# Tasks

Вертикальні задачі: кожна — міграція / функція бази + доменна функція + server action / сторінка + тести, і кожна
робить свої AC спостережуваними сама. Кожна закінчується рядком «Done when» з AC ID; перевірка — `npm test`,
`npm run ac:coverage`, `npm run check:design`, `npm run check:boundary`. Одна задача — одна гілка `task/…` — один PR
«Реалізація» з CodeRabbit, таблицею мутаційної перевірки й рядками `docs/conformance.md`.
