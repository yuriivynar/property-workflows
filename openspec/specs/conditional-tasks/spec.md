# conditional-tasks Specification

## Purpose
Задачі, які показано лише для певної відповіді: шаблон має поле з фіксованими відповідями, запуск показує лише задачі,
що стосуються випадку, а менеджер запуску чи адміністратор змінює відповідь. Джерело — вимога PM
solomchaak/property-workflows-spec#51.

## Requirements

### Requirement: Поле без відповіді під час запуску

WHEN менеджер запускає шаблон із полем-вибором і задачею, яку показано лише для певної відповіді, the system SHALL показати в запуску поле без відповіді й лише задачі без умови, а прогрес рахувати лише за показаними задачами.

#### Scenario: AC-LOGIC-01 Запуск шаблону «Repair»

- **GIVEN** менеджер A і шаблон «Repair» з 4 задачами, одну з яких, «Send an emergency plumber», показано лише коли поле «Urgency» має відповідь «urgent»
- **WHEN** A запускає шаблон для випадку «Apartment 7, leak»
- **THEN** запуск показує поле «Urgency» без відповіді і 3 задачі
- **AND** прогрес — «0 of 3 done»

### Requirement: Відповідь показує умовну задачу

WHEN менеджер запуску або адміністратор відповідає на поле запуску, the system SHALL показати задачі, умова яких збігається з відповіддю, зі статусом «to do» і рахувати їх у прогресі.

#### Scenario: AC-LOGIC-02 Відповідь «urgent»

- **GIVEN** запуск «Apartment 7, leak» з 3 показаними задачами і полем «Urgency» без відповіді, і менеджер A — менеджер запуску
- **WHEN** A відповідає на «Urgency» відповіддю «urgent»
- **THEN** запуск показує 4 задачі
- **AND** задача «Send an emergency plumber» має статус «to do»
- **AND** прогрес — «0 of 4 done»

### Requirement: Прихована задача не блокує завершення

WHILE обов'язкова задача прихована умовою, the system SHALL завершити запуск, щойно виконано й підтверджено всі показані обов'язкові задачі.

#### Scenario: AC-LOGIC-03 Завершення з прихованою обов'язковою задачею

- **GIVEN** запуск з «Urgency» = «not urgent», 3 показаними обов'язковими задачами, 2 з яких «done», і прихованою обов'язковою задачею «Send an emergency plumber»
- **WHEN** виконавець позначає третю показану задачу виконаною і підтверджує
- **THEN** запуск має статус «completed»

### Requirement: Змінена відповідь повертає задачу до «to do»

WHEN менеджер запуску або адміністратор змінює відповідь на поле, the system SHALL повернути до статусу «to do» кожну задачу, умова якої залежить від цього поля.

#### Scenario: AC-LOGIC-04 «not urgent» і знову «urgent»

- **GIVEN** запуск «Apartment 7, leak» з «Urgency» = «urgent», задача «Send an emergency plumber» зі статусом «done», і менеджер A — менеджер запуску
- **WHEN** A змінює «Urgency» на «not urgent», а потім знову на «urgent»
- **THEN** задачу «Send an emergency plumber» показано зі статусом «to do», а не «done»

### Requirement: Відмова в зміні відповіді

IF відповідь на поле запуску намагається змінити користувач, який не є ні менеджером запуску, ні адміністратором, THEN the system SHALL залишити відповідь без змін і показати повідомлення «Only the run manager or an administrator can change the answers».

#### Scenario: AC-LOGIC-05 Виконавець задачі намагається змінити відповідь

- **GIVEN** запуск «Apartment 7, leak» менеджера A і менеджер B — виконавець однієї задачі в ньому, але не менеджер запуску
- **WHEN** B намагається змінити відповідь на «Urgency»
- **THEN** відповідь лишається такою, як була
- **AND** B бачить повідомлення «Only the run manager or an administrator can change the answers»
