# 0010. Next.js 16.4.3 → 16.4.6: патч безпеки в межах зафіксованої лінії 16.4

- Статус: прийнято
- Дата: 2026-11-17
- AC: — (безпека платформи; стосується всіх сторінок і server actions)

## Контекст

`AGENTS.md` фіксує стек («Next.js 16.4 … не оновлювати без ADR»). `npm audit --omit=dev` для `next@16.4.3` показує
GHSA-mfr8-8qww-v76h (**moderate**): розкриття інформації між root params, коли функцію `'use cache'` викликають через
`unstable_cache()`. Уразливі версії — `>=16.3.0 <=16.4.4`, перша виправлена — `16.4.5`. Локальний `next build` на
`16.4.3` зупиняється з нагадуванням про вразливість.

Застосунок не використовує ні `'use cache'`, ні `unstable_cache()`, а Cache Components вимкнено (`AGENTS.md`). Тому
реального шляху до вразливості немає, але залежність лишається в списку аудиту й блокує локальну збірку.

## Рішення

- `next` і `eslint-config-next` — **16.4.6**, точні версії, як в ADR 0005.
- `package-lock.json` згенеровано `npm@11.19.1` (та сама версія, що в CI), тож змінено лише записи `next`, `@next/*` і
  `eslint-config-next`.
- Решту стеку не змінюємо. Рядок «Next.js 16.4» в `AGENTS.md` лишається правдивим.

## Розглянуті варіанти

- **Лишити 16.4.3** — чому ні: застосунок не вразливий, але локальна збірка блокується, а `npm audit` показує `next`.
- **`next upgrade` / найновіша версія** — чому ні: правило «не оновлювати все до latest»; потрібен лише патч безпеки.
- **16.4.5 — перша виправлена версія** — чому ні: 16.4.6 — останній патч тієї самої лінії (як і в ADR 0005).

## Наслідки

- Інші зауваження аудиту (`shadcn` CLI → `ts-morph` → `minimatch`, `hono`) стосуються інструментів розробки й лишаються
  окремим питанням (ADR 0006); з цим PR їх не більшає.
- Наступні патчі безпеки Next.js у межах 16.4 — так само, окремим PR з ADR.

## Як перевіряємо

- `npm audit --omit=dev`: для `next` / `@next/*` вразливостей немає.
- `npm run build` показує `▲ Next.js 16.4.6` і `ƒ Proxy (Middleware)`; `lint`, `typecheck`, `npm test` (362) — зелені;
  CI (`app`) виконує `npm ci` з цим lock-файлом; `/api/health` на проді — SHA злиття.
